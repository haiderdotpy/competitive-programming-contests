# Competitive Programming Write-Ups
My solutions and write-ups to competitive programming contests I take part in.

## Structure
All the directories in the root of the repository are contest numbers (for contests on CodeForces), or contest type (Weekly (W) or Biweekly (BW); for LeetCode), or contest code (for CodeChef). 

All contest directories will have a similar setup. 

1. `[problem_id].cpp` (source code) 
2. `[problem_id]` (executable) 
3. `template.cpp` (template used for the contest) 
4. `write-up.md`
