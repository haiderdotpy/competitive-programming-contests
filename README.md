My solutions and write-ups to competitive programming contests I take part in.

## Structure
All the directories in the root of the repository are contest numbers (for contests on CodeForces and AtCoder), or contest type (Weekly (W) or Biweekly (BW); for LeetCode), or contest code (for CodeChef).
